# AlgeriaEdu

AlgeriaEdu هو نموذج أولي لواجهة تعليمية عربية حديثة، تم تصميمه لتجسيد منصة تعليمية تركز على التعلم، التقدم، والدورات الرقمية.

## المميزات

- صفحة هبوط حديثة وجذابة
- تصميم متجاوب مع مختلف أحجام الشاشات
- أقسام: المزايا، الدورات، من نحن، التواصل
- واجهة مناسبة للتوسيع إلى مشروع كامل لاحقاً

## التشغيل محلياً

يمكنك فتح ملف `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي بسيط:

```bash
cd c:\Users\User\Desktop\1AS-Academy
python -m http.server 8000
```

ثم افتح الرابط التالي في المتصفح:

http://localhost:8000

## الهيكل

- `index.html` — هيكل الصفحة الرئيسية
- `styles.css` — التنسيق والستايل
- `script.js` — السكربت التفاعلي البسيط
